# 민정 팀케어카드 한도체크

법인카드 8341 · 5152의 팀케어 한도 사용액을 확인하는 단일 HTML 앱입니다.

1. `index.html`을 브라우저로 엽니다.
2. 카드별 한도를 입력합니다.
3. 카드사에서 받은 승인내역 엑셀(.xls)을 불러옵니다.
4. 팀케어가 아닌 다른 한도로 쓴 건은 "제외"를 누르고, 일부 금액만 뺄 때는 "수기 차감"을 씁니다.

- 취소건(`29,000 (-29,000)`)은 자동으로 빠집니다.
- 데이터는 서버에 저장하지 않습니다. 한도와 "제외" 표시만 이 브라우저(localStorage)에 기억합니다.
